# referencias/

Sites de referência **deste nicho/categoria**. Servem para calibrar estrutura, tom e nível de acabamento — nunca para copiar.

## Como registrar
Um arquivo por referência: `NN-nome-do-site.md` + print `NN-nome-do-site.png`.

```md
# NN — Nome do site
Link:
Categoria:
O que copiar: (estrutura, hierarquia, uso de foto, CTA...)
O que evitar: (peso, excesso de animação, texto genérico...)
Print: NN-nome-do-site.png
```

## Regras
- Só entra referência **do mesmo nicho** — é o que define o padrão.
- Registrar por que serve, não só o link.
- Print sempre que o site puder sair do ar.
- Máximo 8 referências ativas; acima disso, o padrão deixa de ser padrão.
