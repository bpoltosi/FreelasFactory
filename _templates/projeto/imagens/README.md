## Regras
- Máx. 1600 px de largura, < 500 KB por arquivo.
- Foto de pessoa só com autorização registrada em `briefing.md`.
- Sem banco de imagens genérico. Sem foto → placeholder com a paleta do projeto.
- Não editar o original aqui: versão final vai para `site/assets/`.
