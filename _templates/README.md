# _templates

Peças reaproveitadas por todos os nichos.

| Caminho | Para quê |
|---|---|
| `projeto/` | esqueleto copiado para cada novo cliente |
| `projeto/briefing.md` | formulário de entrada (o "briefing X") |
| `projeto/plano.md` | plano da página, aprovado antes de construir |
| `projeto/qa.md` | checklist base de aceite |
| `projeto/dados/` | dados estruturados do cliente (textos, cardápio, preços) |
| `projeto/imagens/` | material do cliente (logo, fotos) |
| `projeto/site/` | saída: o site em si |
| `projeto/site/index.html` | esqueleto com Fonts, AOS e Lucide já ligados |
| `projeto/site/css/style.css` | tokens, reset e utilitários |
| `projeto/site/js/main.js` | AOS, ícones, menu e ano do rodapé |
| `referencias-README.md` | modelo copiado em cada pasta `referencias/` |
| `projetos-README.md` | modelo copiado em cada pasta `projetos/` |

Ao mudar um template, os projetos já criados **não** são atualizados — template vale para projetos novos.
